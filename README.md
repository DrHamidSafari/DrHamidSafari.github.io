# Dr. Hamid Safari — portfolio

A responsive academic and engineering portfolio for GitHub Pages, inspired by the layout and blue/teal visual style of https://mahdishahmadi.github.io/.

All biography, education, research, experience, publications, and professional links belong to Hamid Safari and were retained from his existing website. The portrait was supplied for this redesign. No Mahdi Ahmadi biography, achievements, publications, or personal images are included.

## Pages

- `index.html`: portrait, introduction, education, teaching, and publications
- `education.html`: degrees, scholarship, and continued learning
- `experience.html`: research and teaching experience
- `projects.html`: engineering projects and technical expertise
- `publications.html`: all seven publications, with topic filters and search
- `resume.html`: printable industry résumé and academic profile

## Editing and hosting

The website is plain HTML, CSS, and JavaScript, with no build step. Publish the root folder on GitHub Pages. Update shared publication and project data in `portfolio.js` and visual styling in `style.css`. Biography and navigation content live in the HTML pages. The theme choice is stored locally in the visitor's browser; reduced-motion preferences disable typing animation.

Keep the `assets` folder with the HTML files. No API keys or server configuration are required. Google Fonts is optional; the page falls back to Arial if it is unavailable.
